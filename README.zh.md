# [Vault Encrypt](https://github.com/hellokunzai/vault-encrypt) Obsidian 加密插件

**把秘密藏进你的 [Obsidian.md](https://obsidian.md/) 仓库。**

[Vault Encrypt](https://github.com/hellokunzai/vault-encrypt) 是一款 Obsidian 社区插件，可以在 Obsidian 中对内容进行加密与解密。你可以加密[整篇笔记](https://github.com/hellokunzai/vault-encrypt)，也可以只加密[笔记中的部分选中文本](https://github.com/hellokunzai/vault-encrypt)，还能对整个文件夹批量加密。

加密后的内容绝不会以明文写入磁盘，你可以放心地同步或备份，无需担心解密后的内容被外泄。

> 本插件由 [Meld Encrypt](https://github.com/meld-cp/obsidian-encrypt) 衍生（fork）而来，并更名为 **Vault Encrypt**，由 <https://github.com/hellokunzai/vault-encrypt> 维护。

## 功能特性

### 1. 整篇笔记加密
加密整篇笔记，没有密码则内容完全不可读。

- **新建加密笔记** —— `Ctrl/Cmd+P` → *新建加密笔记*，或在文件资源管理器中右键文件夹 → *新建加密笔记*。
- **转换现有笔记** —— `Ctrl/Cmd+P` → *转换为加密笔记或反向转换*；或在文件资源管理器中右键 `.md` 文件 → *加密笔记* / 右键已加密文件 → *解密笔记*。
- 加密笔记会以独立的「锁定视图」打开，每次都需要输入密码；你可以**修改密码**，也可以**锁定并关闭**某篇笔记。
- 使用命令 **锁定并关闭所有已打开的加密笔记** 可一次性锁住全部。
- 还可指定**外部密码文件**，让密码从文件路径读取，而无需手动输入。

### 2. 行内加密（Inline Encryption）
只加密笔记中的部分内容，其余部分保持可读。

- **加密选中内容** —— 选中文本后 `Ctrl/Cmd+P` → *加密选中内容*（或右键 → *加密选中内容*）。
- **解密选中内容** —— 右键加密块 → *解密选中内容*（在 Live Preview 实时预览中，该块会被原位替换为原始明文）。在阅读视图中，双击渲染出的 `🔐` 块即可解密查看。
- 加密文本以新的 `encrypt(可见文本){密文}` 格式存储。*可见文本* 在阅读视图中显示为可点击标记；*密文* 为加密后的内容。
- 旧版 `🔐β …` / `🔐α …` 标记仍可解密，保持向后兼容。
- 可附加可选的**密码提示**，帮助你记住密码。

### 3. 文件夹加密

#### 3.1 标记为加密文件夹（自动加密）
把某个文件夹「标记为加密文件夹」后，**该文件夹下新建的 `.md` 笔记会自动转为加密文件**（`.mdenc`）；从别处移入该文件夹的笔记也会自动加密。密码仅保存在内存中（不落盘），按 Obsidian 的安全规范交由 Keychain / 会话缓存管理。

- 在文件资源管理器中右键文件夹 → *标记为加密文件夹*，填写密码（可附提示）、选择是否递归子文件夹、以及是否**同时加密文件夹内已有的笔记**（默认开启）。
- 已标记的文件夹在文件资源管理器中显示 🔒 锁图标，加密文件也会显示锁图标。
- 右键已标记文件夹可 *取消标记*（仅移除标记，不会批量解密）或 *加密现有笔记*。
- 命令 *标记 / 取消标记当前笔记所在文件夹* 作用于当前笔记所在的文件夹。
- 设置页「文件夹加密」下会列出所有标记文件夹，可一键移除；重命名 / 移动 / 删除标记文件夹时，标记会自动跟随或清理。

#### 3.2 一次性批量加密 / 解密
- 在文件资源管理器中右键文件夹 → *解密文件夹*，或命令 *加密当前笔记所在文件夹* / *解密当前笔记所在文件夹*，可对该文件夹（默认递归）一次性批量加 / 解密。
- 处理完成后会汇总成功 / 跳过 / 失败的数量。

### 4. 随机密码生成器
- 通过功能区（Ribbon）图标或 `Ctrl/Cmd+P` → *生成随机密码* 打开弹窗，设置长度（1–256）并勾选字符类型（大写、小写、数字、符号），一键重新生成并复制。

### 5. 会话密码缓存
- 开启 **记住密码** 后，最近使用的密码会按你选择的粒度（整个仓库 / 按文件夹 / 按文件 / 外部文件）缓存，直到 Obsidian 关闭或超过设定时长。
- **清除会话密码缓存** 命令可立即清空缓存。

## 加密原理

所有加密均在本地通过 Web Crypto API（`crypto.subtle`）完成，Obsidian 的桌面端与移动端运行时均支持。插件共存在三套加密方案，通过密文中嵌入的**版本标记**自动识别，因此旧版本生成的密文依然可以解密。**所有新加密一律使用第 2 版（β）。**

| 版本 | 标记 | 密钥派生 | 算法 | 说明 |
| --- | --- | --- | --- | --- |
| **2（默认，β）** | `🔐β` | PBKDF2-HMAC-**SHA-512**，**210,000** 次迭代，随机 16 字节 salt | AES-**256**-GCM，随机 16 字节 IV | 当前标准方案。迭代次数对齐 OWASP 对 PBKDF2-SHA512 的建议。 |
| **1（α）** | `🔐α` | PBKDF2-HMAC-SHA-256，1,000 次迭代，硬编码 salt（`XHWnDAT6ehMVY2zD`） | AES-256-GCM，随机 16 字节 IV | 仅保留用于向后兼容；迭代次数过低且 salt 写死。 |
| **0（废弃）** | `🔐` | 直接用 `SHA-256(password)` 作为密钥 —— 无 PBKDF2、无 salt | AES-256-GCM，**固定** 12 字节 IV | 不安全：nonce 复用叠加无盐密钥。绝不用于生成新密文。 |

### 数据格式

- **整篇 / 文件加密** 写入一个 JSON 信封：`{ "version": "2.0", "hint": "<密码提示>", "encodedData": "<Base64>" }`。Base64 负载的字节布局为 `IV(16 字节) ‖ salt(16 字节) ‖ AES-GCM 密文 + 认证标签`。
- **行内加密** 将 Base64 负载直接嵌入笔记，使用标记 `%%🔐β <负载>`（源码中隐藏）或可见的 `🔐β <负载>`，以及更新的 `encrypt(可见文本){<负载>}` 格式。解密时根据标记识别版本，旧版 `🔐α` / `🔐` 标记同样支持。

### 安全评估

- 默认方案（v2）是主流且稳妥的构造：PBKDF2-SHA512 + 21 万次迭代 + 每次随机 salt + AES-256-GCM 随机 IV。
- 旧版 v0 存在严重缺陷 —— 固定 IV 叠加无盐密钥；v1 使用硬编码 salt 且仅有 1,000 次迭代。二者仅用于解密历史数据，不会被用来生成新密文。

## 安装

### 方式一 —— BRAT（推荐用于测试）
1. 在社区插件中安装 **BRAT** 插件。
2. `Ctrl/Cmd+P` → *BRAT: Add a beta plugin*。
3. 粘贴仓库地址：`https://github.com/hellokunzai/vault-encrypt`。
4. 在「社区插件」中启用 **Vault Encrypt**。

### 方式二 —— 手动安装
1. 从[最新发布页](https://github.com/hellokunzai/vault-encrypt/releases)下载 `main.js`、`manifest.json`、`styles.css`。
2. 将三者复制到 `<vault>/.obsidian/plugins/vault-encrypt/` 目录。
3. 在 **设置 → 社区插件** 中启用 **Vault Encrypt**。

> 更新后请通过 `Ctrl/Cmd+P` → *Reload app without saving* 重新加载，使新的 `main.js` 与 `styles.css` 生效。

## 设置项

| 设置 | 说明 |
| --- | --- |
| **确认密码？** | 开启后，加密操作会要求重复输入一次密码。 |
| **记住密码？** | 缓存最近使用的密码，免去重复输入。 |
| **记住密码（超时）** | 缓存到 Obsidian 关闭，或缓存固定分钟数。 |
| **按以下方式记住密码** | 缓存粒度：仓库 / 文件夹 / 文件 / 外部文件。 |
| **外部文件路径** | 需要时作为密码来源的相对仓库路径。 |
| **行内加密 → 将选区扩展到整行？** | 部分选区在加密前自动扩展为整行。 |
| **行内加密 → 标记搜索范围** | 加密 / 解密时查找标记的最大范围。 |
| **行内加密 → 默认在阅读时显示加密标记** | 行内加密是否在阅读视图中保留可见标记。 |
| **生成随机密码 → 默认长度** | 生成密码的默认字符数。 |
| **生成随机密码 → 字符类型** | 包含大写 / 小写 / 数字 / 符号。 |
| **文件夹加密 → 默认递归处理** | 打开文件夹对话框时默认包含子文件夹。 |
